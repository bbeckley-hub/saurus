🚀 How to Use SAURUS

Four steps from query to genome download — no installation, no account, no limits.

1

Browse a module

Pick a typing scheme (MLST, spa, SCCmec…) or the new Geography page to explore metadata directly.

2

Combine genotype + geography

Stack filters: e.g. ST5 + CC5 + MRSA + United States + blood + mecA. Every module carries country and source columns alongside the typing data.

3

Export accessions

Click 🧬 Accessions to download a plain-text list of matching genome accession IDs — one per line.

4

Download genomes

Feed the list to NCBI: datasets download genome accession --inputfile list.txt — that's it.
