Capsule Typing

Capsular Polysaccharide Serotype
📖 How to read this page
  • Capsule typing determines the capsular polysaccharide serotype of S. aureus — nearly all strains carry either Type 5 (CP5) or Type 8 (CP8), encoded by the cap5/cap8 gene clusters listed in the Genes column.
  • Types are computed via StaphScope, with the typing logic adapted from Riccardo Bollini's StaphSCAN — worth a look, it ships similar S. aureus typing modules.
  • Completeness grades how much of the capsule locus was recovered: Complete, Partial, Fragment or Missing — treat partial and fragment calls with care.
  • To explore: type 5 or type 5 for exact Type 5 rows (same for 8), use the year range and the searchable Source box, and open ⚙ Columns (Show all / Reset) to reveal hidden fields like BioSample, SRA runs and CheckM QC metrics.
  • Every export (TSV, CSV, JSON, accessions, SRA runs…) follows your current filters and selection.
