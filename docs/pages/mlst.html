MLST Typing

Multi-Locus Sequence Typing
📖 How to read this page
  • MLST typing reads the alleles of seven housekeeping genes (arcC, aroE, glpF, gmk, pta, tpi, yqiL) and assigns a sequence type (ST). Allele definitions and ST numbers follow the S. aureus scheme at PubMLST; STs here were computed with Torsten Seemann's mlst tool via StaphScope
  • Clonal complex (CC) groups evolutionarily related STs — ST5, ST6 and friends all sit inside CC5. SAURUS derives CC from the PubMLST ST→CC mapping, so seeing ST239 resolve to CC8 is expected.
  • To explore: type ST5 or CC5 in the search box for an exact match, search the Source box instead of scrolling the dropdown, set a year range, and open ⚙ Columns (Show all / Reset) to reveal hidden fields like BioSample, SRA Runs and QC metrics.
  • Every export (TSV, CSV, JSON, accessions, SRA runs…) follows your current filters and selection, so you can pull exactly the subset you plan to download.
Tip: type ST5 for exact ST, CC5 for clonal complex
