spa Typing

Staphylococcal Protein A Typing
📖 How to read this page
  • spa typing reads the highly variable X region of the protein A gene (spa), a chain of short repeats written as numeric codes, e.g. 15-12-16-02-16-02-25-17-24. The ordered code list is the strain's fingerprint.
  • Each unique repeat order is a spa type named tNNN (t002, t012…), following the definitions at the Ridom SpaServer — the reference database for spa types. Types here are computed with the spaTyper tool via StaphScope.
  • A blue Novel pill means the repeat pattern was typed successfully but is not in the spa database (Ridom SpaServer or the local database used at compute time), so it has no tNNN yet — the raw pattern is in the Repeat Pattern column. Novel rows are counted separately and do not inflate the unique-type numbers.
  • To explore: type t002 for an exact spa type, use the year range and the searchable Source box, and open ⚙ Columns (Show all / Reset) to reveal hidden fields like BioSample, SRA runs and CheckM QC metrics.
  • Every export (TSV, CSV, JSON, accessions, SRA runs…) follows your current filters and selection.
