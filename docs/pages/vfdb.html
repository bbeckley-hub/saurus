About this dataset

This page lets you retrieve genomes by Virulence gene content. Pick up to 5 genes, choose whether samples must match any or all of them, and download the accession list — perfect for re-downloading genomes for downstream analysis.

Source

Gene presence/absence is derived from the Shelenkov et al. (2025) dataset:

Shelenkov A, Mikhailova Y. Genomic Typing, Antimicrobial Resistance Gene, Virulence Factor and Plasmid Replicon Dataset for the Important Pathogenic Bacteria Staphylococcus aureus. BMC Genomic Data (2025).

How to use it

  1. Click a quick-pick gene chip (or use the search filter in Tab 2)
  2. Optionally add up to 4 more genes — the table updates instantly
  3. Switch between Match ANY (union) and Match ALL (intersection)
  4. Click 🧬 Accessions to download the accession list as plain text
  5. Use the TSV/CSV/JSON exports to get per-gene presence flags for each accession

Why accession retrieval matters

Genome retrieval is the most common use case for a surveillance resource: you want all genomes that carry mecA, or all PVL-positive isolates, or all samples with both tet(M) and erm(B). SAURUS gives you the accession list directly — paste it into datasets download genome accession --inputfile list.txt and you have the genomes.
