Methicillin-Resistant Staphylococcus aureus — Master View
📖 How to read this page
  • This master table merges every typing module — MLST, spa, SCCmec, capsule and agr — into one row per genome, so you can filter on combinations like ST5 + t002 + SCCmec II.
  • MRSA vs MSSA: MRSA status is determined by whether the mec cassette was detected. StaphScope runs two independent SCCmec callers — CGE SCCmecFinder and the sccmec RPET caller — and this page prefers the CGE result, falling back to rPET. Genomes where neither caller finds the cassette are listed as MSSA / Unknown.
  • The CC (clonal complex) column is derived from the ST via a majority-vote lookup of the MLST clonal-complex table (cc.txt), so every ST carries its most commonly observed CC.
  • The two SCCmec callers can disagree (see the columns SCCmec (RPet) and SCCmec (CGE)); both are kept so you can judge borderline calls yourself.
  • To explore: type ST5 for an exact ST or CC5 for an exact clonal complex, use the year range and the searchable Source box, and open ⚙ Columns (Show all / Reset) to reveal the QC fields (CheckM completeness, contamination, N50…). The MRSA Breakdown tab shows how each typing value splits across MRSA / MSSA / Unknown.
  • Every export (TSV, CSV, JSON, accessions, SRA runs…) follows your current filters and selection.
Tip: type ST5 for an exact ST · CC5 for an exact clonal complex
