📖 How to use these files

All files are gzipped TSV. Decompress locally then open in pandas, R, or any tool:

gunzip mlst_all.tsv.gz
head -5 mlst_all.tsv

Or read directly from Python without extracting:

  • pd.read_csv('mlst_all.tsv.gz', sep='\t') — pandas (auto-decompresses)
  • read.delim('mlst_all.tsv.gz', sep='\t') — R

🧬 Long-format gene files

amr_all.tsv, vfdb_all.tsv, plasmid_all.tsv are long format — one row per present (sample, gene). To pivot to wide:

df.pivot_table(index='accession', columns='gene',
               values='num_hits', fill_value=0)
