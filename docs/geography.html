📖 About this data

All metadata comes from NCBI BioSample records attached to the RefSeq and GenBank assemblies. Country, isolation source, host, and collection year are extracted from the standard BioSample attributes. Sources have been normalized into broad categories (blood, nasal/screening, skin/wound, food, respiratory, …); raw values are preserved in the TSV/CSV/JSON exports as country_raw and source_raw. Blank cells are shown as — — the underlying data is genuinely missing, not filtered out. The SRA coverage figure reflects NCBI SRA deposition: 16.6% of genomes in this collection have publicly available raw reads, retrieved via BioProject-batched queries. Use the SRA Run column in the export to feed fastq-dl and the SRA Toolkit.
