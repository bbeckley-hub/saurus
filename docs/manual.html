🚀 Quick Start

The most common workflow is filter → verify → export. Here's the whole thing in four commands: 

$ saurus --lineage USA300 --count
# Step 1: how many USA300 genomes exist globally?
$ saurus --lineage USA300 --country USA --source blood --count
# Step 2: narrow to USA bloodstream isolates
$ saurus --lineage USA300 --country USA --source blood -o usa300_blood.txt
# Step 3: export the accession list
$ datasets download genome accession --inputfile usa300_blood.txt --filename usa300_blood.zip
# Step 4: download the genomes from NCBI
That's it. Four commands, four steps — from "I want USA300 bloodstream isolates from the USA" to "I have the genome files on my laptop." No scripting, no intermediate files, no pipeline.

📦 Installation

SAURUS CLI is a lightweight Python package. It requires Python 3.8+ and pandas. No other dependencies. No root access. The full 134,160-genome dataset is bundled inside every distribution, so queries run locally with no downloads, no API keys, and no network access after install.

Choose whichever method fits your workflow. All five methods deliver the same CLI and the same bundled data.

pip (standard)

$ pip install saurus-cli

uv (fastest)

$ uv tool install saurus-cli

pipx (isolated environment)

$ pipx install saurus-cli

conda (Bioconda)

$ conda install -c bioconda saurus-cli

Docker

$ docker pull bbeckleyhub/saurus-cli:latest
$ docker run --rm bbeckleyhub/saurus-cli:latest --version

Verify the install

$ saurus --version
$ saurus --lineage USA300 --count
Data files: The full SAURUS dataset ships bundled inside the pip distribution. You only need to run saurus init if you want to manually refresh the data bundle to the latest release. If you installed via Docker, the data is already baked into the image.

🎯 Your First Query

Once installed, run the banner — it shows your version, affiliation, and a quick-start reference: 

$ saurus --examples
# Show the full example gallery
$ saurus --about
# Show author, affiliation, citations, and links

Now try your first real query — count USA300 genomes:

$ saurus --lineage USA300 --count

You should see a number like 10,448. That's the number of USA300 genomes in the SAURUS database right now.

Override a component

For example, USA300 is globally distributed. Restrict it to Japan: 

$ saurus --lineage USA300 --country Japan --count

The USA300 signature supplies ST8, t008, SCCmec IV, agr I, capsule 5. Your --country Japan flag overrides nothing — it just adds a filter on top. But if you also passed --spa t437, that would override the signature's t008.

📊 Counting Genomes

Get a number fast — perfect for checking how much data exists before you commit to downloading.

USA300 globally

💡 Returns 341 genomes.

📤 Exporting Accessions

Every query exports a clean accession list. You can also export metadata tables, SRA runs, BioSamples, and BioProjects in one command.

Plain-text accession list
The format 95% of downstream pipelines actually consume.
$ saurus --lineage USA300 -o usa300.txt
💡 Exports 10,448 accessions.
Metadata table AND accession list together
One command → two files. Verify the rows, then feed the list downstream.
$ saurus --lineage USA300 --format tsv,accession -o usa300_results
💡 Produces usa300_results.tsv and usa300_results.txt.
Everything, all at once
TSV + JSON + accession list — three files, one command.
$ saurus --lineage EMRSA-15 --format tsv,json,accession -o emrsa15_results

📥 SRA Raw Reads

Export SRA run accessions directly for fastq-dl. 22,322 genomes in the database have retrievable raw reads.

Count genomes with raw reads
Filter only genomes that have a retrievable SRA run.
$ saurus --has-sra --count
💡 Returns 22,322 genomes.
Export SRA runs
Get a clean list of SRR/ERR/DRR accessions for fastq-dl.
$ saurus --lineage USA300 --format sra -o usa300_runs
💡 Exports 1,821 unique SRA runs for USA300.
Export BioSamples and BioProjects
For sample-level metadata or study-level tracking.
$ saurus --lineage USA300 --format biosample,bioproject -o usa300_meta
💡 Produces usa300_meta_biosamples.txt and usa300_meta_bioprojects.txt.

🧬 Genotype Queries

Filter by gene content across the AMR, virulence, and plasmid modules. Match ALL (default) or ANY with --any.

PVL-positive ST8
lukS-PV is the toxin marker that made USA300 famous.
$ saurus --st 8 --vfdb lukS-PV --count
💡 Returns 258 genomes.
MRSA with mecA and tetM
Match ALL genes — the default AND logic.
$ saurus --amr mecA,tetM --count
💡 Returns genomes containing both genes.
Multi-drug resistant (match ANY)
mecA OR tetM — the OR logic. Returns a massive set.
$ saurus --amr mecA,tetM --any --count
💡 Returns 134,273 genomes.
Plasmid replicon filter
Find genomes carrying a specific plasmid replicon — useful for horizontal-gene-transfer studies.
$ saurus --plasmid rep5a --count
💡 Returns 21,619 genomes.

🐞 Diagnostics

When a query returns 0 genomes, --debug shows you exactly where the count dropped. The #1 time saver.

Debug an impossible genotype
ST5 is never agr I / capsule 8 — the USA100 genotype is agr II / capsule 5.
$ saurus --st 5 --agr I --capsule 8 --debug --count
💡 Shows the exact step where it drops to 0.
Quiet mode for pipelines
Suppresses banner, footer, and quote — clean stdout for scripting.
$ saurus --lineage USA300 -q | head -5
💡 Exits silently when piped — no BrokenPipeError.

📤 Multi-Format Output

Need both the metadata table and the accession list? Request both in one run. You can also export SRA runs, BioSamples, and BioProjects directly.

Two files, one command

$ saurus --lineage USA300 --format tsv,accession -o usa300_results
# produces usa300_results.tsv + usa300_results.txt

Three formats at once

$ saurus --lineage EMRSA-15 --format tsv,json,accession -o emrsa15_results
# produces usa300_results.tsv, .json, and .txt

Which format should I use?

FormatBest forExtension
accession Downstream NCBI datasets downloads, pipeline integration .txt
sra Raw reads — pipe directly to fastq-dl or prefetch _sra_runs.txt
biosample Sample metadata or fastq-dl --group-by-sample _biosamples.txt
bioproject Study-level bulk downloading _bioprojects.txt
tsv Excel, R, pandas, Spotfire — tab-separated for easy parsing .tsv
csv Sharing with collaborators who prefer CSV, or MS Access .csv
json Web apps, jq, JavaScript, reproducible archival .json
Tip: If you pass --output without a recognized extension, SAURUS appends the correct one for each format. So -o usa300_results works — you don't have to add .tsv.

🔁 Reproducible Configs

For recurring surveillance tasks, save your query as a JSON config file and share it with collaborators. Anyone with the same dataset will reproduce your exact result set.

Create usa100_surveillance.json

{
  "lineage": "USA100",
  "country": "United States",
  "source": "blood",
  "mrsa": true,
  "year": "2020-2025",
  "format": "tsv,accession",
  "output": "usa100_surveillance_2020_2025"
}

Run it

$ saurus --config usa100_surveillance.json
Reproducibility guarantee: When you email that JSON file to a collaborator, they run the same command and get identical results — byte-for-byte, assuming the same SAURUS data release. This is exactly the reproducibility model that journals and funders are asking for.

Override a config value from the command line

Config values are defaults. Any command-line flag overrides the corresponding config field: 

$ saurus --config usa100_surveillance.json --country Japan
# runs the same query but for Japan instead of the United States

⚙️ Pipeline Integration

SAURUS CLI is designed to fit into existing pipelines. It reads from ./data/, writes to stdout, and exits silently when piped.

Pipe accessions directly into NCBI datasets

$ saurus --lineage USA300 | datasets download genome accession --inputfile /dev/stdin --filename usa300.zip
# No intermediate file needed

Chain with other tools

$ saurus --lineage USA300 -q | wc -l
# Count how many genomes match (quiet mode, no banner)
$ saurus --lineage USA300 -q > accessions.txt && datasets download genome accession --inputfile accessions.txt --filename usa300.zip
# Shell pipeline — download immediately

Use in a Snakemake or Nextflow rule

Because saurus exits silently when piped and accepts --quiet, it can be called directly from any pipeline tool:

# Snakemake rule
rule download_usa300:
    output: "data/usa300_accessions.txt"
    shell:
        "saurus --lineage USA300 --country USA -q -o "
Quiet mode matters: always pass -q when calling saurus from a pipeline or script. It suppresses the banner, quote, and marketing footer — so the only thing that reaches your stdout is the data.

🐞 Troubleshooting

Zero matches — but the query should work?

The most common reason a query returns 0 is that the genotype you're asking for doesn't exist in nature. For example, ST5 + agr I + capsule 8 is impossible — USA100 is agr II + capsule 5. Run with --debug to see exactly where the count drops: 

$ saurus --st 5 --agr I --capsule 8 --debug --count
# shows which filter is the culprit

You'll see something like:

  [debug] Initial load: 134,160 rows
  [debug] --st 5: 14,930 rows
  [debug] --agr I: 0 rows       ← the culprit

Master file not found

The CLI needs a master TSV at data/mrsa/mrsa_all.tsv. If it's missing, regenerate it: 

$ python scripts/build_master_tsv.py

BrokenPipeError when piping to head / less

This is not a bug — it's Python's default behavior. SAURUS CLI suppresses it automatically since v0.2. If you're on an older version, upgrade: 

$ pip install --upgrade saurus-cli

Command not found: saurus

The package wasn't installed correctly. Try reinstalling with the dash:

$ pip install saurus-cli
# note: if using dev mode, it is "-e .", not "e ." — the dash matters!

Still stuck?

Open an issue at github.com/bbeckley-hub/saurus/issues — include your terminal command and the --debug output.
